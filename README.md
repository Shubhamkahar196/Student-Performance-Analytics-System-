# Student Performance Analytics System

## Project Overview
A Python-based data analysis project that processes student marks and attendance to generate academic performance reports.

## Objectives
- Calculate total and average marks for each student.
- Assign grades using defined grading criteria.
- Identify passed and failed students.
- Analyze overall class and subject-wise performance.
- Identify top-performing students.
- Analyze attendance and department-wise averages.

## Technologies Used
- Python
- Pandas
- NumPy
- CSV

## Dataset
The sample dataset contains 20 student records with Student ID, Name, Department, subject marks and Attendance.

## Project Features
1. Student dataset loading using Pandas.
2. Total and average marks calculation.
3. Grade assignment.
4. Pass/Fail identification.
5. Class performance summary.
6. Subject-wise performance analysis.
7. Top 5 performers.
8. Attendance analysis.
9. Department-wise performance analysis.
10. Export of processed results to CSV.

## Installation and Execution

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the program from the directory containing `main.py`:

```bash
python main.py
```

## Output
The program displays student results and performance statistics in the terminal and can save processed results to `student_results.csv`.
