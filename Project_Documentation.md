# Project Documentation

## 1. Project Title
Student Performance Analytics System

## 2. Objective
To analyze student academic performance using Python, NumPy and Pandas and generate meaningful summaries from student marks and attendance.

## 3. Technologies Used
Python, NumPy, Pandas and CSV.

## 4. Dataset Description
The dataset contains 20 sample student records. Fields include Student ID, Name, Department, Python marks, Mathematics marks, Data Science marks, English marks and Attendance.

## 5. Implementation
1. Read the CSV dataset using Pandas.
2. Display the dataset and its columns.
3. Calculate total and average marks for every student.
4. Assign grades using if-elif-else conditions.
5. Determine Pass/Fail status based on subject marks.
6. Calculate class average, highest and lowest performers, and pass percentage.
7. Calculate subject-wise and department-wise averages.
8. Display the top five performers.
9. Identify students with attendance below the defined threshold.
10. Export processed results to a CSV file.

## 6. Key Features
- Marks summary
- Grade assignment
- Pass/Fail statistics
- Subject-wise analysis
- Top performers
- Attendance analysis
- Department-wise analysis
